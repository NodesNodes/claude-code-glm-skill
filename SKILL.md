# Claude Code → GLM Coding Plan

Переключи Claude Code на GLM через Anthropic-совместимый endpoint Z.ai. Сохрани существующие настройки и проверь результат реальным запуском Claude Code.

## Подключение

1. Проверь `claude --version` и настройки выбранного пользователя: обычно `~/.claude/settings.json`. Проверь переменные окружения и настройки проекта на переопределение модели, endpoint и режима разрешений. Скрипт убирает конкурирующие `ANTHROPIC_MODEL`, `ANTHROPIC_API_KEY` и флаги Bedrock/Vertex/Foundry из поля `env` целевого файла. Унаследованные shell-переменные и другие файлы он не меняет: устрани обнаруженный конфликт в источнике, который действительно определяет текущий запуск. Показывай имена переменных и состояние ключа, скрывая его значение.
2. Нужна действующая подписка **Z.ai GLM Coding Plan** и ключ из **Personal Coding Plan → Plan Overview** либо соответствующего Team Coding Plan. Это ключ доступа к квоте подписки; сам факт использования API-ключа не означает оплату каждого токена. Ключ обычного API может использовать другой баланс. Подписка Claude Pro/Max к GLM не относится.
3. Если ключ уже сохранён для endpoint Z.ai, его можно использовать повторно. Иначе предложи сохранить ключ в локальный защищённый файл или в переменную `ZAI_CODING_PLAN_API_KEY`. Не проси вставлять секрет в чат или аргументы команды. Вход `zcode login` относится к ZCode: его OAuth-токен нельзя просто подставить вместо ключа Coding Plan в Claude Code. При отсутствии подходящего ключа оставь рабочую конфигурацию до его получения.
4. Выполни скрипт из каталога этого скила:

   ```bash
   python3 scripts/configure_glm.py configure --key-file /absolute/path/to/coding-plan.key
   ```

   При уже заданной `ZAI_CODING_PLAN_API_KEY` или сохранённом ключе Z.ai достаточно:

   ```bash
   python3 scripts/configure_glm.py configure
   ```

Скрипт использует стандартную библиотеку Python, создаёт приватную резервную копию рядом с настройками, объединяет поля и атомарно сохраняет JSON. Он не печатает ключ. По умолчанию выбираются `glm-5.3`, `glm-5.3-flash` для Haiku и контекст 1 000 000 токенов. Для другой модели передай `--model`, `--fast-model` и её подтверждённый `--context-tokens`.

## Проверка

Запускай проверку из пустого временного каталога, чтобы не отправлять контекст рабочего проекта. Сначала проверь ответ модели:

```bash
claude --setting-sources user --tools "" \
  --system-prompt 'Connectivity check. Reply exactly OK.' \
  --no-session-persistence --output-format json -p 'Reply exactly OK.'
```

В JSON проверь `is_error: false`, ответ `OK` и **фактическое имя** модели в `modelUsage`, а также `contextWindow`. Цена `costUSD` в выводе Claude Code не доказывает списание денег за токены у Z.ai: источник квоты проверяется в Coding Plan.

Затем проверь выполнение одной безвредной локальной команды в том режиме разрешений, которым пользуется пользователь. Например, попроси Claude Code вызвать Bash с `python3 -c "print(17 + 25)"`; ожидаемый результат — `42`. Один текстовый ответ ещё не подтверждает работу инструментов. В `-p` обычный режим может отклонить команду, требующую подтверждения: используй интерактивное подтверждение либо авторизованный пользователем auto mode, без обхода разрешений.

После изменения настроек перезапусти Claude Code. Для продолжения прежнего диалога запускай `claude --continue` из исходного рабочего каталога. В `/model` будет отдельный пункт GLM-5.3.

## Контекст и auto mode

- `Model "glm-5.3" isn't recognized · context assumed to be 200k` означает, что Claude Code не знает размер окна этой модели. Скрипт задаёт `CLAUDE_CODE_MAX_CONTEXT_TOKENS=1000000` для GLM-5.3 без суффикса `[1m]` и регистрирует модель через `ANTHROPIC_CUSTOM_MODEL_OPTION`. Не выдавай GLM за конкретную модель Claude через `modelOverrides`.
- Уведомление о бесплатных classifier requests относится к поддержке нового серверного механизма auto mode у провайдера. Оно само по себе не означает ошибку подписки. Отдельные проверки могут расходовать её квоту.
- Если auto mode ждёт проверок или провайдер не поддерживает server-side review, на Claude Code **2.1.302+** можно оставить проверки на клиенте и выбрать поддерживаемую GLM Flash:

  ```bash
  python3 scripts/configure_glm.py configure --client-auto
  ```

  Это задаёт `CLAUDE_CODE_AUTO_MODE_SERVER=0` и `CLAUDE_CODE_AUTO_MODE_MODEL=glm-5.3-flash`. Проверки остаются включёнными; существующие правила разрешений и `autoMode` сохраняются. Флаг не включает auto mode в сессии сам по себе. Повтори проверку Bash и проверь `permission_denials`. Если задержка остаётся, смотри ошибку classifier и доступность выбранной модели. Само `Waiting…` не доказывает причину задержки.
- Сообщения `unrecognized_model` в диагностическом stderr могут сохраняться даже при правильном `contextWindow`. Отдельно оценивай предупреждение интерфейса и успешность запроса.

## Состояние и возврат

```bash
python3 scripts/configure_glm.py status
python3 scripts/configure_glm.py restore --backup /absolute/path/to/settings.before-glm.TIMESTAMP.json
```

`status` выводит только выбранные параметры и наличие ключа. Восстановление сначала сохраняет текущую конфигурацию и затем заменяет её указанной копией. Это полный снимок: учитывай изменения, сделанные после его создания. Копии содержат прежние секреты и должны храниться вне git. По завершении сообщи модель, результат проверки и путь к резервной копии; не утверждай, что переключение завершено, пока ключ отсутствует или проверка не прошла.
